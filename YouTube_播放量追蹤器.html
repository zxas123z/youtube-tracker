設定 YouTube API Key

本應用完全運行於您的瀏覽器前端，數據直接向 Google YouTube API 查詢。請填入您的 YouTube Data API v3 金鑰。

如何免費獲取 API Key？

  1. 前往 Google Cloud Console
  2. 建立新專案並啟用「YouTube Data API v3」
  3. 至「憑證」分頁建立 API 金鑰並貼於上方

使用與輸入說明

支援的輸入格式：

  • 影片網址：https://www.youtube.com/watch?v=dQw4w9WgXcQ
  • 影片 ID：dQw4w9WgXcQ
  • 頻道網址：https://www.youtube.com/channel/UC...
  • 頻道 Handle：@YouTube

資料儲存與安全性：

所有追蹤項目與 API Key 均僅保存在您的個人瀏覽器本地 (localStorage)，不會傳送至任何第三方伺服器。
